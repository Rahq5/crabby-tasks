# Overview

Todo-list app is made in rust.
a digital tool that helps you capture, organize, schedule, and track tasks so you finish work on time and avoid forgetting things all in your CLI.

# Functional Requirements

1. FR-01: User should be able to create new tasks
2. FR-02: User should be able to edit the task name
3. FR-03: User should be able to delete the task 
4. FR-04: User should be able to mark the task with these states:
	1. COMPLETED
	2. PENDING
	3. NOT COMPLETED
5. FR-05: User should be able to assign importance level to each task 
6. FR-06: User should be able to view all tasks
7. FR-07: User should be able to run rust only from their CLI
